# Criz Leung — Creative Portfolio

Personal creative portfolio website for video editing, visual design, AI image, AI video, and creative systems.

## Files

- `index.html` — main portfolio page
- `style.css` — responsive styling

## Recommended Cloudflare deployment

This repository is a plain static website. Use Cloudflare Pages / static deployment settings:

- Framework preset: None
- Build command: leave blank
- Deploy command: leave blank if Cloudflare allows it; if required, use a static Pages flow instead of a Worker deploy flow
- Output directory: `/` or repository root
- Production branch: `main`

## Video usage

Do not upload large video files directly into this repo. Upload showreels and project videos to YouTube or Vimeo, then embed them in `index.html`.
